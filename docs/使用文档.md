# 校园通知智能待办系统 V3

> 本地跑的小模型，把 QQ 群里的通知自动变成桌面待办。
> 不需要联网、不调用云端 API、不占你打游戏时的显存。

---

## 一、三步启动

| 步骤 | 操作 | 说明 |
|---|---|---|
| 1 | 双击 `tools\1_start_all.bat` | 启动服务 + 自动打开控制台 |
| 2 | 浏览器里打开 `http://127.0.0.1:8000/console/` | 如果没自动打开，手动输这个地址 |
| 3 | 双击 `tools\3_start_desktop.bat` | 桌面端（可选，托盘常驻用） |

**第一次用之前**，先到「配置」页添加你要监控的群号，否则一条消息都不会收。

## 五、游戏模式（重点）

你打游戏时，系统会自动让路：

```
检测到游戏进程
    ↓
立刻把模型从显存卸载（1~3 秒）
    ↓
游戏期间：消息只存队列，用纯正则判断是否紧急（<0.05ms）
    ↓
紧急的 → 弹窗 + 推手机 QQ
普通的 → 存着，等你打完
    ↓
游戏退出 → 自动把积压的消息批量处理完
```

**三种模式**（在仪表盘切换）：

| 模式 | 行为 |
|---|---|
| 自动检测 | 默认。发现游戏进程就让路 |
| 强制游戏 | 手动。模型不加载（适合玩别的游戏时） |
| 强制日常 | 手动。即使游戏在跑也加载模型（**会有显存风险，会弹警告**） |

**如果自动检测不准**（游戏进程名对不上）：
1. 进游戏，打开任务管理器 → 详细信息
2. 找到游戏的 exe 名字（比如 `DeltaForceClient-Win64-Shipping.exe`）
3. 到配置页 →「游戏进程名」里加上

**不要加启动器**（`*launcher.exe`）和反作弊（`ACE-Tray.exe`），它们常驻后台，会让系统一直以为你在玩游戏。

## 六、手机访问

1. 配置页 → 打开「允许局域网」
2. 点「随机生成」得到令牌
3. 保存
4. 手机连同一 WiFi，浏览器打开：
   ```
   http://电脑IP:8000/console/?token=你的令牌
   ```
5. 查电脑 IP：命令行执行 `ipconfig`，看「IPv4 地址」

**注意**：校园网是同网段几千台机器，**不设令牌等于把待办公开**。

## 七、出问题怎么办

| 现象 | 原因 | 怎么修 |
|---|---|---|
| 页面打不开 | 服务没启动 | 跑 `tools\check_env.py` |
| 收到消息但没待办 | 群号没填 | 配置页加群号 |
| 一直显示「游戏中」 | 进程名误判 | 检查「游戏进程名」是否包含 launcher |
| 模型加载失败 | Ollama 没跑 | 命令行执行 `ollama serve` |
| 提示「待人工确认的通知（AI 暂不可用）」 | LLM 调用失败 | 检查 Ollama 和模型，这些通知没丢，可手动处理 |
| 数据库损坏 | 掉电/强杀进程 | 服务会自动从 `.bak` 恢复；也可以手动跑 `check_env.py` |

## 八、技术要点（答辩用）

| 设计决策 | 理由 |
|---|---|
| 视频/图片走 OCR 而非视觉大模型 | 实测 easyocr 1.09 秒/张、7 个关键信息全中；视觉模型要 6 GB 显存，跑不动 |
| 用 `related_task_id` 而非标题匹配做变更检测 | 实测同一任务两种说法 difflib 相似度仅 0.333，字符串匹配必失效 |
| LLM 输出用 `model_validator` 字段级兜底 | 实测 `title=null` 会让整条通知消失，比崩溃更隐蔽 |
| webhook 立刻返回 + 单 worker 队列 | 实测同步阻塞 18.6 秒会超时丢消息，改成 2~16 ms 返回 |
| 游戏期间禁用一切 GPU 推理 | 8GB 显存要留给游戏；且 GPU 推理会抢功耗导致 CPU 降频、1% Low 帧暴跌 |
| 数据库开 `synchronous=FULL` | E 盘是 exFAT 无日志机制，掉电易损坏 |
| SSE 只推内存快照 | 生成器里查库会阻塞事件循环，导致 webhook 收不到消息 |

## 十二、日常使用流程

```
开机
  ↓ 自动
服务在后台跑（静默，无窗口）
  ↓
QQ 群里有通知
  ↓
系统自动解析 → 待办出现
  ↓
你打开 http://127.0.0.1:8000/console/ 看
或者双击 tools\3_start_desktop.bat 用桌面端
```

**打游戏时**：

```
检测到游戏进程
  ↓
模型自动卸载，显存让出来
  ↓
消息只入队，不解析（但不丢）
  ↓
退出游戏 → 自动补处理 → 待办出现
```
